席ごとに課金するプラン（[サブスクリプション](/subscriptions)を参照）のほかに、ワークスペースは次の 2 種類のプランを使えます。金額は VND です。

## 無制限プラン

無制限プランには、数量に関する上限がありません。タスク数、オートメーションの実行回数、エージェント、ランタイム、ストレージはすべて制限なしです。課金は引き続き席ごとで、既定のカタログでは両方のアカウント種別が購入できます。

「無制限」は無限という意味ではありません。API のリクエストレートはプラットフォーム共通の上限の範囲内に収まり、監査ログの保持期間にも上限があります。

## 従量課金プラン

従量課金プランには席がなく、前払いもありません。ワークスペースを使い、月が終わってから請求書が届きます。

開始するには、**設定 → 請求とプラン** でこのプランを選びます。すぐに有効になり、注文の金額は 0 です。事前に請求先プロフィールの入力が必要です。

- 個人アカウントには、名前（支払者名）と請求送信用メールアドレスが必要です。
- 法人アカウントには、4 項目すべてが必要です。[サブスクリプション](/subscriptions)を参照してください。

このリリースでは、有料の席課金プランを使っているワークスペースは従量課金プランに切り替えられません。

利用量は UTC の日ごとに、3 つのメーターで集計されます。

| メーター | 集計の内容 |
|---|---|
| タスク実行 | その日に完了したエージェントの実行。失敗した実行は数えません。 |
| ストレージ | その日の終わりの添付ファイルのバイト数。月額料金はその月の日数で按分します。 |
| メンバー | その日の終わりのメンバー数。月額料金はその月の日数で按分します。 |

各日はプランの料金で計算され、計算時の価格とともに 1 行として保存されます。そのため、後から価格を変更しても過去の日は変わりません。停止中のワークスペースは 0 として計算されます。**今期の使用量** カードには、当月の各メーターの数量、料金、金額が表示されます。

## 利用料請求書

UTC の月初に、前月の各日が 1 通の利用料請求書にまとめられます。請求書には `BILLING_VAT_RATE` の税率で VAT が加算されます（未設定の場合は 10%）。ほかの注文と同じく銀行振込で支払い、期限切れにはなりません。**請求書** の **詳細を表示** で、日ごとの明細を確認できます。

- **最低金額。** 最低金額に満たない月次請求書は発行されず、その明細は翌月に繰り越されます。既定の最低金額は 10,000 VND で、`PLATFORM_USAGE_MIN_INVOICE` で設定します。従量課金プランを離れるときに発行される最終請求書には、最低金額がありません。
- **支払期限。** 利用料請求書が 7 日間（`PLATFORM_USAGE_DUE_DAYS`）未払いのままだと、サブスクリプションは `past_due` になります。
- **未払いの請求書。** 未払いの利用料請求書がある間は、有料プランの購入や変更ができません。バナーからその請求書を開けます。無料プランへの変更はできます。

## 利用限度額

従量課金プランには、アカウント種別ごとに利用限度額を設定できます。これは、発生済みでまだ請求書になっていない利用料の金額です。お使いのアカウント種別に限度額が設定されていないプランには、限度額がありません。

- **80%** に達すると、カードに警告が表示され、owner と admin にその月 1 回メールが届きます。
- **100%** に達すると、未請求の利用料すべてについて暫定請求書がすぐに発行されます。最低金額はありません。

限度額によって利用が止まることはありません。

## 法人割引

プランは、法人アカウントに利用料の割引率を設定できます。割引は `business` アカウントにだけ適用されます。既定では、staff が請求先プロフィールを確認済みにしている場合だけ適用されます。管理者が `PLATFORM_BUSINESS_DISCOUNT_REQUIRES_VERIFICATION` を `false` にすると、すべての法人アカウントが対象になります。各メーターと請求書の明細行には、計算に使った割引が表示されます。法人名または税番号を変更すると、確認済みの状態は解除されます。

<Callout type="info">
割引の端数処理は、請求書全体ではなく、日ごとの明細行ごとに 1 回行われます。
</Callout>
