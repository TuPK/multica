アカウントグループは、グループに入っているメンバーに、ロールに加えて追加の権限を与えます。たとえば、経理担当者に請求を閲覧させたり、運用担当者にメンバーを招待させたりできます。どちらも `admin` にする必要はありません。

グループは、owner と admin が **設定 → グループ** で管理します。ほかのロールにはこのタブが表示されません。グループの管理を開く権限キーもないため、グループを使って自分の権限を引き上げることはできません。

<Callout type="info">
アカウントグループがプランに含まれるのは、`member_groups` の上限が 0 より大きい場合だけです。上限が 0 のプランには機能が含まれず、グループの作成は拒否されます。既定のカタログでは、Free と Pro には含まれず、Business はワークスペースごとに最大 50 グループ、無制限プランと Enterprise には上限がありません。
</Callout>

## グループを作成する

**グループを作成** を選び、次を設定します。

- **名前。** 1〜64 文字で、ワークスペース内で一意です。`Finance` と `finance` は同じ名前として扱われます。
- **説明。** 任意で、最大 280 文字です。
- **権限。** 下の 6 つの権限キーから任意に選びます。
- **メンバー。** ワークスペースのメンバーを検索して追加します。1 回のリクエストで追加できるのは 100 人までで、1 つのグループには 1,000 人まで入れられます。1 人が複数のグループに入ることもできます。追加できるのは、現在のワークスペースのメンバーだけです。

変更は、その人の次のリクエストから反映され、再ログインは不要です。グループを削除するか、メンバーをグループから外すと、そのグループが付与していた権限はすぐになくなります。

## 6 つの権限キー

| キー | 開放される内容 |
|---|---|
| `members.invite` | メンバーの招待、保留中の招待の管理、共有リンクの作成。`admin` は招待できません。 |
| `audit.read` | ワークスペースの監査ログの閲覧 |
| `billing.view` | ワークスペースの注文とその利用明細の一覧表示と表示、および **請求とプラン** タブの表示 |
| `billing.manage` | 注文の購入者情報の編集。`billing.view` を含みます。 |
| `integrations.manage` | GitHub、バージョン管理、Qoder などの連携の接続と切断 |
| `runtime_profiles.manage` | カスタムランタイムプロファイルの作成、編集、削除 |

owner と admin は常に 6 つすべてのキーを持ちます。グループは `member` ロールにキーを追加するだけで、取り除くことはありません。複数のグループのキーは合算されます。

<Callout type="warning">
現時点では、`billing.manage` があっても一般のメンバーはサブスクリプションを変更できません。プランの購入と変更、席の追加、解約、再開、請求先プロフィール、そして **請求とプラン** タブの利用量の表示には、引き続き `owner` または `admin` のロールが必要です。[サブスクリプション](/subscriptions)を参照してください。
</Callout>

## viewer

グループによって `viewer` が書き込めるようになることはありません。`audit.read` や `billing.view` を持つグループに入っている viewer は、そのキーが開放する内容を読み取れます。対応するキーを持っていても、書き込みはすべて viewer ロールによって拒否されます。[メンバーとロール](/members-roles)を参照してください。

## エラー

| メッセージ | 原因 |
|---|---|
| 同じ名前のグループがすでに存在します。 | 大文字小文字を区別せず、既存のグループと名前が一致しています。 |
| グループには最大 1,000 人まで追加できます。 | グループが満員です。 |
| 1 回に追加できるのは 100 人までです。 | 1 回のリクエストで 100 人を超える人を指定しました。 |
| このプランではアカウントグループを利用できません。 | プランの `member_groups` の上限が 0 です。 |
| このワークスペースのアカウントグループ上限に達しています。 | ワークスペースのグループ数が、プランで許可されている数に達しています。 |
