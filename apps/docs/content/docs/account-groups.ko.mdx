계정 그룹은 그룹에 속한 멤버에게 역할에 더해 추가 권한을 줍니다. 예를 들어 재무 담당자가 결제를 볼 수 있게 하거나 운영 담당자가 멤버를 초대할 수 있게 하면서, 둘 다 `admin`으로 만들 필요가 없습니다.

그룹은 owner와 admin이 **설정 → 그룹**에서 관리합니다. 다른 역할에는 이 탭이 보이지 않습니다. 그룹 관리를 여는 권한 키도 없으므로 그룹으로 자신의 권한을 높일 수 없습니다.

<Callout type="info">
계정 그룹은 요금제의 `member_groups` 한도가 0보다 클 때만 포함됩니다. 한도가 0이면 요금제에 이 기능이 없고 그룹 생성은 거부됩니다. 기본 카탈로그에서 Free와 Pro에는 포함되지 않고, Business는 워크스페이스당 최대 50개, 무제한 요금제와 Enterprise는 상한이 없습니다.
</Callout>

## 그룹 만들기

**그룹 만들기**를 선택하고 다음을 설정합니다.

- **이름.** 1~64자이며 워크스페이스 안에서 고유해야 합니다. `Finance`와 `finance`는 같은 이름으로 취급합니다.
- **설명.** 선택 사항이며 최대 280자입니다.
- **권한.** 아래 여섯 가지 권한 키 중 원하는 것을 고릅니다.
- **멤버.** 워크스페이스 멤버를 검색해 추가합니다. 한 번의 요청으로 최대 100명을 추가할 수 있고, 한 그룹에는 최대 1,000명이 들어갑니다. 한 사람이 여러 그룹에 속할 수 있으며, 현재 워크스페이스 멤버만 추가할 수 있습니다.

변경 사항은 해당 멤버의 다음 요청부터 적용되며 다시 로그인할 필요가 없습니다. 그룹을 삭제하거나 멤버를 그룹에서 제거하면, 그 그룹이 준 권한이 즉시 사라집니다.

## 여섯 가지 권한 키

| 키 | 열리는 기능 |
|---|---|
| `members.invite` | 멤버 초대, 대기 중인 초대 관리, 공유 링크 생성. `admin`은 초대할 수 없습니다. |
| `audit.read` | 워크스페이스 감사 로그 읽기 |
| `billing.view` | 워크스페이스의 주문과 사용량 내역을 목록으로 보고 열기, 그리고 **결제 및 요금제** 탭 보기 |
| `billing.manage` | 주문의 구매자 정보 편집. `billing.view`를 포함합니다. |
| `integrations.manage` | GitHub, 버전 관리, Qoder 같은 연동 연결과 해제 |
| `runtime_profiles.manage` | 커스텀 런타임 프로필 생성, 편집, 삭제 |

owner와 admin은 항상 여섯 개 키를 모두 가집니다. 그룹은 `member` 역할에 키를 더할 뿐 빼지 않으며, 여러 그룹의 키는 합쳐집니다.

<Callout type="warning">
현재 `billing.manage`로는 일반 멤버가 구독을 변경할 수 없습니다. 요금제 구매와 변경, 좌석 추가, 취소, 재개, 결제 프로필, 그리고 **결제 및 요금제** 탭의 사용량 수치에는 여전히 `owner` 또는 `admin` 역할이 필요합니다. [구독](/subscriptions)을 참고하세요.
</Callout>

## viewer

그룹이 `viewer`에게 쓰기 권한을 주지는 않습니다. `audit.read`나 `billing.view`가 있는 그룹에 속한 viewer는 그 키가 여는 내용을 읽을 수 있습니다. 해당 키를 가지고 있어도 모든 쓰기는 viewer 역할이 거부합니다. [멤버와 권한](/members-roles)을 참고하세요.

## 오류

| 메시지 | 원인 |
|---|---|
| 같은 이름의 그룹이 이미 있습니다. | 대소문자를 구분하지 않고 기존 그룹과 이름이 같습니다. |
| 그룹에는 최대 1,000명까지 포함할 수 있습니다. | 그룹이 가득 찼습니다. |
| 한 번에 최대 100명까지 추가할 수 있습니다. | 한 요청에 100명이 넘는 사람을 지정했습니다. |
| 이 요금제에서는 계정 그룹을 사용할 수 없습니다. | 요금제의 `member_groups` 한도가 0입니다. |
| 이 워크스페이스의 계정 그룹 한도에 도달했습니다. | 워크스페이스의 그룹 수가 요금제가 허용하는 수에 이르렀습니다. |
