账号组为组内成员在其角色之上授予额外权限。比如让财务人员查看账单、让运营人员邀请成员，而不必把他们设为 `admin`。

owner 和 admin 在 **设置 → 账号组** 中管理账号组。其他角色看不到这个标签页，也没有任何权限键能打开账号组管理，所以没有人能借助账号组提升自己的权限。

<Callout type="info">
只有套餐的 `member_groups` 限额大于零时，才包含账号组。限额为零表示套餐不含该功能，创建账号组会被拒绝。在默认目录中，Free 和 Pro 不含账号组，Business 每个工作区最多 50 个，不限量套餐和 Enterprise 没有上限。
</Callout>

## 创建账号组

点击 **创建账号组**，然后设置：

- **名称。** 1 到 64 个字符，在工作区内唯一。`Finance` 和 `finance` 视为同一个名称。
- **描述。** 可选，最多 280 个字符。
- **权限。** 下面六个权限键的任意组合。
- **成员。** 搜索工作区成员并添加。一次请求最多添加 100 人，一个账号组最多容纳 1,000 人。一个人可以属于多个账号组，且只能添加当前的工作区成员。

修改在对方的下一次请求时生效，无需重新登录。删除账号组或把某人移出账号组，会立即收回该组授予的权限。

## 六个权限键

| 权限键 | 开放的内容 |
|---|---|
| `members.invite` | 邀请成员、管理待接受的邀请、创建分享链接。不能邀请 `admin`。 |
| `audit.read` | 查看工作区审计日志 |
| `billing.view` | 列出并打开工作区的订单及其用量明细，并看到 **账单与套餐** 标签页 |
| `billing.manage` | 编辑订单上的买方信息。包含 `billing.view`。 |
| `integrations.manage` | 连接和断开 GitHub、版本控制和 Qoder 等集成 |
| `runtime_profiles.manage` | 创建、编辑和删除自定义运行时配置 |

owner 和 admin 始终拥有全部六个权限键。账号组为 `member` 角色增加权限键，从不移除，多个账号组的权限键会叠加。

<Callout type="warning">
`billing.manage` 目前还不能让普通成员更改订阅。购买套餐、更改套餐、添加席位、取消、恢复、账单资料，以及 **账单与套餐** 标签页上的用量数据，仍然需要 `owner` 或 `admin` 角色。参见[订阅](/subscriptions)。
</Callout>

## viewer

账号组不会让 `viewer` 获得写入权限。属于带有 `audit.read` 或 `billing.view` 的账号组的 viewer，可以读取该权限键开放的内容。即使 viewer 持有对应的权限键，每一次写入仍会被 viewer 角色拒绝。参见[成员与权限](/members-roles)。

## 错误

| 提示 | 原因 |
|---|---|
| 已有同名账号组。 | 名称与现有账号组相同，忽略大小写。 |
| 每个账号组最多包含 1,000 位成员。 | 账号组已满。 |
| 每次最多添加 100 位成员。 | 一次请求中的人数超过 100。 |
| 当前套餐不支持账号组。 | 套餐的 `member_groups` 限额为零。 |
| 该工作区已达到账号组数量上限。 | 工作区的账号组数量已达套餐允许的上限。 |
